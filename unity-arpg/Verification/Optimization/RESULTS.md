# ARPG 优化实施与验收

日期：2026-11-06。项目：余烬行者 / unity-arpg。最终构建使用 Unity 6000.3.23f1、Unity CLI 1.0.0-beta.17，在本机生成 Windows 非开发版。

入口：[Emberfall.exe](../../Builds/Emberfall/Emberfall.exe)。源码和本地构建已更新。

## 已完成的优化

| 范围 | 最终行为 |
| --- | --- |
| 交互 | 提示与 E 共用最近且可见的掉落目标；入口、篝火优先于掉落；满背包不挡出口；回程从对应来路进入区域；击杀停顿期间也接受拾取、血瓶和保存输入。 |
| 战斗 | 攻击前摇与命中帧分开，前摇期间移动减速；技能优先于按住的普通攻击，支持 0.25 秒缓冲；朝向、距离和遮挡共同参与索敌。 |
| 墙体与敌人 | 近战、范围技能和弹体不能穿墙；弹体检查整段移动轨迹；敌人通过共用导航场绕过古墓隔墙，远程敌人保持距离。 |
| 闪避与反馈 | K 闪避持续 0.2 秒、冷却 2.2 秒，短暂无敌且受墙体阻挡；加入挥砍弧、受击停顿、伤害数字、目标标记和敌人血条。 |
| 动作与声音 | 新增四方向主角待机、两帧步行和攻击，保留受击、闪避及死亡表现；九种原创程序合成音效，M 切换静音并保存。 |
| 装备成长 | 精制、稀有装备附带疾速、汲取或凝神词缀；营地行囊中 V 出售、R 强化，最多三级；实际价格、词缀与属性比较可见。 |
| 首领与重复游玩 | 首领半血后进入更快的第二阶段，并发射六向弹体；每次通关提高后续远征难度，最高五阶。 |
| 界面 | J/U/I/O/K 图标及冷却遮罩、剩余秒数；行囊武器/护甲图标、词缀、强化等级和操作按钮；更新 F1 中文手册。 |
| 性能与结构 | 每区 1 个平铺地面替代 1,056 个地板对象；复用特效、弹体和伤害数字；背包仅在数据改变时刷新；拆分动态 Canvas，缓存文本；战斗、规则、导航及反馈分别维护。 |
| 存档 | 保持版本 1 兼容，旧装备默认无词缀、零强化；新增字段和静音偏好可往返保存；无效装备条目尝试备份恢复。 |

操作细节见 [README](../../README.md)。新增角色图集及完整生成提示见 [ART_SOURCES](../../ART_SOURCES.md)。本轮保持固定地图和既有原型规模，未引入联网、技能树或随机地图。

## 性能测量

修改前后使用相同 `PerformanceVerification` 脚本、随机种子、180 帧采样、16 件满背包、30 敌人战斗负载及 60 FPS 上限。战斗夹具给予玩家和敌人足够生命，持续请求攻击，避免采样中断；它不是正常难度通关测试。

修改前的采样使用隐藏窗口，因此只将隐藏窗口的对象数量和同步场景生成耗时并列比较，不据此宣称 GPU 或可见窗口 FPS 提升。源数据：[Before](Before/performance.csv)、[VerifiedAfter](VerifiedAfter/performance.csv)。

| 场景 | 修改前 SpriteRenderer 数量 | 最终数量 | 减少 |
| --- | ---: | ---: | ---: |
| 营地 / 满背包 | 1,369 | 315 | 77.0% |
| 30 敌人战斗 | 1,444 | 407 | 71.8% |
| 古墓 | 1,162 | 111 | 90.4% |

数量来自 `FindObjectsByType<SpriteRenderer>`，不是绘制调用数。

| 同序切图样本 | 修改前同步生成耗时（毫秒） | 最终同步生成耗时（毫秒） |
| --- | ---: | ---: |
| 营地，第 1 次 | 11.223 | 3.343 |
| 荒野，第 1 次 | 8.260 | 2.642 |
| 古墓 | 12.712 | 4.138 |
| 荒野，第 2 次 | 10.980 | 3.686 |
| 营地，第 2 次 | 10.982 | 2.771 |

切图耗时指 `EnterZone` 同步执行时间，不含随后渲染与延迟销毁。CSV 的 `zone_*` 行是单次样本：`median_ms` 列承载此同步时间，`p95_ms` 列承载等待下一帧后的总历时；这两列在切图行不表示统计分位数。

最终版本可见窗口、1440×900 截图分辨率下的独立帧时间采样如下。它包含 60 FPS 帧率限制下的等待时间，不能等同于 CPU/GPU 净耗时。

| 场景 | 帧数 | 中位帧时间（毫秒） | P95（毫秒） | P99（毫秒） |
| --- | ---: | ---: | ---: | ---: |
| 营地待机 | 180 | 16.669 | 16.739 | 16.889 |
| 满背包打开 | 180 | 16.669 | 16.801 | 16.968 |
| 30 敌人战斗 | 180 | 16.679 | 16.928 | 19.216 |

非开发版的 `GC Allocated In Frame` 计数器不可用，CSV 为 `-1`，没有据此报告 GC 分配降低比例。上述为单机短时采样，不是长时间压力测试或所有硬件的帧率保证。

## 复验入口

从工程目录构建：

```powershell
unity run . --timeout 300 --log-file Verification/Optimization/build.log --no-tail -- -executeMethod Emberfall.Editor.PrototypeSetup.Build
```

构建程序支持以下参数。输出目录应使用新的绝对路径，画面验收需保留可见窗口：

```text
-optimization-check -optimization-output <绝对目录>
-emberfall-smoke -smoke-output <绝对目录>
-keyboard-journey -journey-output <绝对目录> -native-input-probe
-emberfall-performance -performance-output <绝对目录>
```

普通启动不传入这些参数即可正常游玩。
