# 风帆海战

Windows 键鼠单人海战。主菜单选择船型，点击「开始航行」即担任海盗船的船长。小型单桅船配 1 名船长、4 名炮手和 1 名损管，中型双桅船配 1 名船长、9 名炮手和 2 名损管。其余船员由 AI 操作。敌船与玩家船型相同，悬挂海军旗，由 AI 船长指挥。

每次开局，双方所有火炮都是空炮。玩家和 AI 船员在炮位装填一发需要 5 秒，在破口修补一处需要 3 秒，均按游戏时间计算。各炮位完成装填且目标进入射界后即可开火。遇到已装好、能瞄准的空炮位，附近船员会沿甲板过去接管。只剩一名可行动的 AI 时，他会逐门打出本舷已经装好的炮弹，再装填续射。损管繁忙时炮手也能补漏，空闲的损管员也能补炮位。

玩家可以随时离舵换岗，按 E 接手已有船员使用的岗位。船长阵亡时，能最快走到舵位的存活船员接替掌舵。到位后，代理舵手会根据敌船的方位和距离转舵、调帆，必要时起锚或下锚。右侧值舵栏显示代理舵手的岗位和实际舵向。临时舵手若是唯一幸存者，也可暂离舵位开炮。船长复活后收回掌舵权。

点击主菜单的「战斗测试」可直接进入中型双桅船的主甲板。甲板上有两个使用水手模型的假人，各有 100 点生命，画面右上角显示各自的血量。假人生命耗尽时倒地，10 秒后在原位恢复满血。按 F8 可重新开始练习。

## 启动

已有本地 Windows 构建时，双击 `play.cmd`。在 Unity 中可用 6000.3.23f1 打开本目录，打开 `Assets/Scenes/SeaTrial.unity` 后点击 Play。通过编辑器菜单 `Galleon / Build Windows player` 重新生成独立程序。

## 操作

| 位置 | 键位 |
| --- | --- |
| 主菜单 | 鼠标点击船型以预览，点击「开始航行」登船。也可用方向键移动焦点，回车确认 |
| 甲板 | WASD 移动，Shift 奔跑，鼠标环顾，滚轮调整镜头。空格原地起跳，配合方向键可按奔跑速度越过栏杆跳海 |
| 手持物品 | 1 拔出手枪，2 拔出砍刀，3 拿出药瓶。再按同一个数字键收起。进入岗位、游泳或攀梯时自动收起手持物品 |
| 手枪 | 拔枪后枪口放低。点右键举枪，中央准星出现。瞄准时可用 WASD 移动，点左键开枪，再点右键放低。每次命中造成 50 点伤害 |
| 手枪装填 | 开火后需持枪装填 5 秒，放低枪口仍会继续装填。收起手枪或换成砍刀、药瓶时暂停装填，再次拔枪从剩余时间继续 |
| 砍刀 | 靠近并面向目标，点击左键挥砍。持续按住左键可左右交替连砍，每一挥对同一目标造成一次 25 点伤害 |
| 药瓶 | 持药时点一次左键，1 秒后恢复 50 点生命，最高 100 点。喝药时可以走动或奔跑，中途收起或切换物品会取消本次喝药 |
| 海面 | 落入外海后使用 WASD 游泳 |
| 舷侧登船梯 | 游到梯面即可攀爬。W 上爬，S 下爬，A 向左，D 向右，可组合斜移。松开方向键会停在梯上。越过侧边或底端会下落，爬过舷缘即可上甲板。在甲板上面向船内，按 S 退到梯口可沿原梯下船。单桅船每侧一架，双桅船每侧两架 |
| 岗位旁 | 按一次 E 接手，再按一次 E 中断并离开 |
| 舵轮 | 靠近后按 E 掌舵，A、D 转舵。停泊时按 W 起锚并放半帆，再按 W 放满帆。按 S 逐档收帆，从半帆完全收起时自动下锚。按 E 离舵 |
| 炮位 | 按 E 接手后，以第一人称从炮口瞄准。准星每小格 1°，3° 和 6° 处有数字。移动鼠标瞄准，左键或空格发射。空炮会自动装填。再次按 E 离开，恢复第三人称。炮膛被淹时无法操作，排水至炮膛以下后恢复使用 |
| 破口 | 靠近并面向闪红的裂纹，按一次 E 开始修补。修好后贴花消失，船员自动离岗 |
| 舱底泵 | 在泵柄旁按一次 E 持续排水。小型单桅船的泵在露天甲板中线，中型双桅船的泵在中央舱梯下方的炮层。船壳仍漏水时会继续压泵，破口已补且舱水排干后自动离岗 |
| 演练 | F6 在自己的船上触发两处漏点。补好并抽干后可再次演练 |
| 其他 | F1 或 Esc 打开操作说明并暂停，再按一次继续。点击「返回选船」可结束本局换船，F8 使用当前船型重新开局 |

新航程从收帆下锚开始。离开舵轮时，船会维持当前帆档。两船相遇时，船壳会挡住彼此。斜擦时仍能沿对方船侧航行，停锚的船可作为靠船的一侧。当前碰撞只影响航行。

破口进水会让船身逐渐下沉。封堵会同时清除这一处船内和船外的中弹贴花，船舱中已有的水要到水泵处排出。上甲板被海水完全淹没时船只沉没。击沉海军战舰获胜，自己的船沉没则战败。结算后可点击「返回选船」，或按 F8 再次驾驶当前船型。

火炮最大射程约为 500 游戏米，从开火炮位沿水平方向测量。炮弹入水后，在平均海面下 6 米以内仍可击中船壳。我方和敌方 AI 炮手会随目标下沉调整瞄点。不同炮位轮换瞄准船侧的不同高度。对中型双桅船开火时，炮手也会间歇瞄准艉楼两侧的船壳，命中后可能波及舵手。某处超出当前炮位的射界时，炮手会改瞄其他可达区域。

炮弹击中船体或船员时，按弹着点到每名船员身体的最近直线距离结算伤害，包含甲板之间的高差。1.8 米以内（含）扣 100 点，超过 1.8 米至 3 米（含）扣 50 点，3 米以外不扣血。每发炮弹对每人只结算一次。重复命中同一点时，即使破口移到邻位或附近已无空位，仍按这次炮弹的实际碰撞点扣血。[炮手与船长的实测范围图](Design/cannon-impact-crew-r06.png)

屏幕右侧的击杀列表显示击杀者、武器和阵亡者。我方海盗用蓝青色，敌方海军和训练假人用珊瑚红，玩家本人显示为「你」。列表保留最近 5 条，每条显示 6 秒。舷炮击杀归属实际开炮的船员，一发击倒多人时逐人显示。

屏幕左上角的「船员生命」显示当前血量，满血为 100。从高处落到硬面时按着陆冲击扣血。正常跳跃和落入外海时不会扣血。连续游泳 20 秒会溺亡，最后 5 秒会出现警告和倒计时。阵亡后，血条归零并开始 10 秒复活倒计时。若本船仍未沉没，计时结束后船员会在本船下层舱内随机选取可站立的位置满血复活。打开操作说明暂停游戏时，倒计时也会暂停。

每处破口的大小和进水速度相同。连续命中已有破口时，会优先在同舷、距弹着点 3.4 米以内寻找最近的空位。只有船员能站到内侧并够到破口、且内外贴花均有空间，才会新增破口。附近位置用尽后，继续命中不会加快进水。每次修补只封住当前破口。

## 船模

游戏载入 `Assets/Naval/Resources/Fleet` 下的两套模型。各船的 `Rig.json` 记录 Blender 源文件名和 SHA-256，可用于核对本地模型版本。

| 船型 | Blender 源文件（相对 `D:\workspace\blender`） | 游戏资源目录 | 导出脚本 |
| --- | --- | --- | --- |
| 小型单桅船 | `small-sloop/model/Small_Sloop_R06.blend` | `Fleet/Sloop` | `Tools/export_sloop.py` |
| 中型双桅船 | `medium-brigantine/model/Medium_Brigantine_R06.blend` | `Fleet/Brigantine` | `Tools/export_brigantine.py` |

水手来自 `sailor/model/Deckhand_R06.blend`。跳跃和攀梯沿用奔跑动作。入水后，水手每秒完成一轮交替划臂、打腿和侧身换气。松开方向键时原地划水。

水手战斗动画也使用这套骨架。手枪动作根据 `sailor/tmp/weapon-shot-preview-v4` 的动作脚本与分镜烘焙。左右挥刀采用 `sailor/tmp/weapon-cutlass-preview-v3` 的三维横挥动作，对应 `05-cutlass-sweep-v3.gif`。两段都由右手持刀，横挥时刀面平行于甲板，换向时翻腕，让亮刃始终朝向挥动方向。
