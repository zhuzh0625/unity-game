## 弯道连接优化（2026-10-30）

按用户截图修复护栏交叉、外侧缺口及红白路缘错位。原先固定 8 米直段不能贴合弯道内外侧的不同弧长；赛道偏移方向还在采样点发生跳变，最大相邻偏移跳步约 0.907 米。

- 改为插值共享横断面，沿赛道生成连续护栏、白色反光条和红白路缘；首尾闭合，红白色块交替连接。
- 护栏立柱延伸到路肩，碰撞边界使用连续闭合网格，替换相互重叠或留缝的直段盒碰撞体。
- 网格更新改用显式顶点/索引更新，解决 Unity 场景视图可能继续显示旧几何缓存的问题。
- 护栏、反光条及路缘的分段接头最大间隙为 0（含环线首尾）；全线 5,494 次护栏碰撞射线检查通过。沿中心线前后相隔 2 毫米取样，偏移点最大距离为 3.196 毫米，符合弯道外侧弧长变化，不再出现原有跳变。报告：`roadside-verification.txt`。
- 1,374 次道路碰撞采样及比赛规则检查通过；三圈物理自动驾驶回归正常，玩家用时 183.37 秒，四车零异常复位。报告：`roadside-drive-verification.json`。
- 更新后的 Windows 构建约 133 MiB；1600×900 独立运行验收通过，30 秒平均约 100.7 FPS，推进 12 个检查点、零异常复位，退出码为 0。报告：`roadside-native-verification.json`。
- 已保存同一视角的修改前后截图：`roadside-before.png`、`roadside-after.png`。源场景、生成网格及相关代码的修改前副本保存在本地 `tmp/roadside-before-20261030-144724/`。

## 复验入口

1. 普通试玩运行 `play.cmd`。Enter 开始，WASD 或方向键驾驶，空格手刹，R 复位，Esc 暂停。
2. 全键盘重开：Esc → ↓ → Enter。暂停菜单选中框应移到“重新开始”，确认后计时归零并重新倒计时。
3. 自动输入验收：从项目根目录运行 `verify-keyboard.cmd`。会短暂打开游戏窗口，自动完成操作并退出，报告写入 `doc/keyboard-verification.json`。
4. 重新构建需要先打开本项目 Unity Editor，再执行 `build.cmd`。场景和美术源文件入口见项目 `README.md`。

Git 交付包含 Unity 源工程、资源及 `.meta`、Blender 源文件、构建脚本和说明文档；构建包、缓存及本地验收材料由 `.gitignore` 排除。
